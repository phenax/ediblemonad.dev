Coding is a niche hobby again!

For a while programming was one of the best career options for someone to pick. Still is to some extent. But there was a time before all of this when computers weren't everywhere as they are now and majority of programmers were just nerds with a niche hobby.

With the whole AI takeover of the industry, the value of code went all the way down. With that a lot of people lost interest in writing code by themselves. Just like before, the value of code is as low as it was back then and writing code is not really a job. We've come full circle.

This at first made me feel like shit. Mainly because of the huge discrepency between how I feel about coding and how the world does now. But that feeling was short-lived because as it turns out, I still feel the same way about code as I did when I first started. It's still as satisfying and enjoyable as the first "hello world". Yeah most of the software industry now uses AI to produce code, but thats alright. I can still write my own code in my free time and I still love doing it!

There's so much depth to programming, so many rabit holes to dive into and so much more to learn that coding as a hobby will stay fun for me for the foreseeable future. I won't be using AI for any of the code I write for fun because I don't care about producing hobby code faster. It's hobby code. I wouldn't use an ice-cream eating robot to eat my ice-cream for me just because it can do it faster.

So yeah, coding's just a niche hobby again. And it's a really fun one!
