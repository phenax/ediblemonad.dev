# Coding is a niche hobby again!

For a while programming was one of the most lucrative career options for someone to pick. Still is to some extent. But there was a time before all of this when computers weren't everywhere as they are now and majority of programmers were just nerds with a niche hobby.

With the whole AI takeover of the industry, the value of code has gone all the way down. A lot of people have lost interest in writing code by themselves. The value of code is as low as it was back then and writing code is not really a job anymore. We've come full circle.

This at first made me feel sad about the state of things. Mainly because of the huge discrepency between how I feel about coding and how the world does now. But that feeling was short-lived because as it turns out, I still feel the same way about code as I did when I first started. It's still as satisfying and enjoyable as the first "hello world". Yeah most of the software industry now uses AI to produce code, but thats alright. I can still write my own code in my free time and I still love doing it!

There's so much depth to programming, so many rabit holes to dive into and so much more to learn that coding as a hobby will stay fun for me for the foreseeable future. I won't be using AI for any of the code I write for fun because I don't care about producing hobby code faster. I wouldn't use an ice-cream eating robot to eat my ice-cream for me just because it can do it faster or better.

So yeah, coding's just a niche hobby again. And it's a really fun one!
